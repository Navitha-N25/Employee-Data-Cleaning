# Messy Employee Dataset Cleaning

# Project URL: https://roadmap.sh/projects/clean-csv

## Project Overview
Cleaned and validated a messy employee dataset using Python and Pandas.

## Objectives
- Inspect the original dataset.
- Handle encoding and delimiter issues.
- Fix column data types.
- Convert date columns using `pd.to_datetime()`.
- Standardize categorical values.
- Handle missing values.
- Export the cleaned dataset and perform a final audit.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Project Files
- `employee_data_cleaning.ipynb` — Data cleaning code.
- `cleaned_employee_dataset.csv` — Cleaned output dataset.

## Final Audit
Checked data types, missing values, duplicate records, invalid dates, and exported file consistency.

## Dataset Source
[Kaggle – Messy Employee Dataset](https://www.kaggle.com/datasets/desolution01/messy-employee-dataset)
